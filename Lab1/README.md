# Лабораторна робота 1. Реалізація та перевірка зворотного поширення похибки

## Запуск та відтворення

Запуск з папки `Lab1`:

```powershell
uv run --locked --python 3.12 lab1.py
uv run --locked --python 3.12 lab1.py --bug
```

Перша команда виконує базовий правильний розрахунок, а друга запускає дослід з навмисно внесеною помилкою без ділення на розмір вибірки. Усі версії бібліотек зафіксовані у файлах `pyproject.toml` та `uv.lock`.

Покроковий процес обчислень і проміжні виводи також наведені в блокноті [lab1.ipynb](lab1.ipynb).

## Опис даних та архітектури

- Використано датасет Iris (150 прикладів, 4 ознаки, 3 класи).
- Вибірку розбито стратифіковано у співвідношенні 70/30 (по 35 прикладів кожного класу в навчання і по 15 у тест) за допомогою генератора `np.random.default_rng(0)`.
- Стандартизація виконана за середнім та стандартним відхиленням (`ddof=0`), обчисленими виключно на навчальній вибірці.
- Обчислення виконуються у форматі `float64`.
- Мережа: `Linear(4, 8) -> ReLU -> Linear(8, 3)`.
- Ваги ініціалізовані новим генератором `np.random.default_rng(0)` за методами He для першого шару та Xavier для другого. Зміщення ініціалізовані нулями.
- Розмір навчальної вибірки: N = 105.

## Формули прямого та зворотного ходу

Прямий прохід:

```text
Z1 = X @ W1 + b1                (105, 8)
A1 = max(0, Z1)                 (105, 8)
Z2 = A1 @ W2 + b2               (105, 3)
M_i = max_j Z2_ij               (105, 1)
log P_ij = Z2_ij - M_i - log sum_k exp(Z2_ik - M_i)
Loss = -(1/N) sum_i log P_i,y_i
```

Зсув на максимум запобігає переповненню експоненти при розрахунку softmax. У прямому проході зберігаються проміжні значення `Z1`, `A1` та ймовірності `P`.

Зворотний прохід:

```text
D2 = (P - Y) / N                (105, 3)
dL/dW2 = A1.T @ D2              (8, 3)
dL/db2 = sum_i D2_i             (3,)
D1 = (D2 @ W2.T) * (Z1 > 0)     (105, 8)
dL/dW1 = X.T @ D1               (4, 8)
dL/db1 = sum_i D1_i             (8,)
```

## Прогноз досліду з помилкою

Якщо прибрати ділення на N у градієнті логітів D2:

- Значення функції втрат на початкових вагах не зміниться, оскільки прямий прохід залишається без змін.
- Усі ненульові градієнти стануть рівно у 105 разів більшими, оскільки подальші кроки зворотного ходу є лінійними відносно D2.
- Звірка градієнтів із PyTorch і числові похідні покажуть розбіжність, а перевірка значення втрати буде пройдена.
